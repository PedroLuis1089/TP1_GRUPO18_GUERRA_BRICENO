# TP1 Babys en Desarrollo Web

## Descripción del proyecto.

    Iniciamos el trabajo práctico con el objetiivo fundamentaal de poner en práctica lo estudiado en la materia Frond End y afrontar de la mejor manera posible los desafíos que representan para nosotros los requerimientos del mismo.

    Realizamos una web que incluye navegacion desde la página principal (portada) a las tarjetas de presentación de los integrantes del grupo, a una bitacora.

## Tecnologías utilizadas.

    - HTML.
    - CSS.
    - JavaScript.
    - Google Fonts.
